# AgentSINC identity directions

The supplied `AgentSINC Logo.html` contains three logo-sheet directions. All use a hexagonal network mark: three outer nodes connected to a central hub. The wordmark reads **AgentSINC**, with the SINC portion accented. The supplied tagline is **Innovation · Network · Collaboration**.

The three alternatives are preserved as options:

| Option | Primary palette | Accent | Character |
|---|---|---|---|
| A — Cyan + Violet | Navy `#0B1020` | Cyan `#22D3EE`, violet `#8B5CF6` | Technical, luminous, futuristic |
| B — Ember | Charcoal `#16110D` | Orange `#FF7A1A`, amber `#FFC857` | Warm, energetic, bold |
| C — Indigo + Lime | Indigo `#1E1B4B` | Lime `#A3E635`, green `#4D7C0F` | Confident, modern, high contrast |

The simple vector marks are stored in `public/brand/`. They are lightweight scalable assets, not screenshots of the logo sheet.

## Decision still open

Do not finalize the full interface palette until the SINC team selects A, B or C. In the meantime use neutral UI tokens and make the theme easy to swap.

## Usage rules

- Preserve the spelling `AgentSINC`.
- Use `SINC` for the organization name.
- Keep the tagline exactly as supplied unless the founder requests a change.
- Use the full wordmark in the main navigation and the standalone mark for compact icons.
- Keep a high-contrast version for dark and light surfaces.
