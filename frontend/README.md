# AgentSINC frontend

This directory will contain the original AgentSINC Next.js application.

Planned responsibilities:
- Dashboard, agent roster, task board, chat and approvals.
- Original custom Three.js / React Three Fiber office scene.
- Accessible 2D fallbacks for important workflows.
- Authenticated API client and live event subscriptions.

The frontend must not own durable agent/task state or expose provider credentials. Implementation begins in Phase 2 after the Phase 1 foundation is reviewed.
